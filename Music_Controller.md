# Music Controller
---
This is a simple and easy to use **Media Controller** made with [.NET](https://learn.microsoft.com/de-de/dotnet/) and the [Avalonia UI](https://avaloniaui.net/) Framework.

It displays the **title, artist, thumbnail and timeline** of the Media that is currently playing.
There are also **buttons to play, pause, skip and skip to the previous song**.

When the Program starts a **tray icon** appears on the taskbar, which can **open up the settings menu** or **exit the Program** when right clicked.

## Settings Menu
The Settings Menu has the following options to change the User experience:
- **Toggle Animations**
- **Rearrange/Drag Mode** (used to reposition the Overlay to ones liking)
- **Reset Postion** (used to reset the position of the Overlay to prevent it from going off-screen or getting stuck)
- **Trigger Key + Modifiers** (change the key for activating the Overlay)
